# 🔱 DRISHTI — Hierarchical Skill Graph Output

## 📦 Deliverables

1. **master_skill_graph.json** — Complete skill graph (JSON-LD format)
2. **interactive_graph.html** — Interactive visualization (open in browser)
3. **report.md** — Pipeline execution report

## 🚀 Usage

Open `interactive_graph.html` in a web browser to explore the graph.

The JSON-LD graph is compatible with:
- NetworkX (Python)
- Neo4j (graph database)
- Robot learning frameworks (RT-2, Octo, OpenVLA)
